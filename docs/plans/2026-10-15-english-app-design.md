# 英语听说学习 App 设计文档

日期：2026-10-15
用户水平：CEFR A2（听力 A1–A2 为主要短板），iPhone 用户，碎片化学习

## 1. 目标与范围

- 一个可"添加到主屏幕"的网页 App（PWA），iPhone Safari 为主，Mac 浏览器可用
- 纯离线可用，无账号、无服务器，数据只存本机
- 本期不做：AI 自由对话（预留入口）、多设备同步、推送通知

## 2. 技术方案

| 项 | 选择 | 理由 |
|---|---|---|
| 框架 | Vite + Preact + TypeScript | 体积小、启动快，适合手机 |
| 离线 | vite-plugin-pwa（Service Worker 预缓存） | 首次加载后可断网使用 |
| 存储 | IndexedDB（`idb` 库） | 可存音频 Blob 和大量学习记录 |
| 发音 | `speechSynthesis`（iOS 自带英文语音） | 免费、可调速、可逐句 |
| 识别 | `webkitSpeechRecognition`（en-US） | iOS Safari 原生支持，国内可用 |
| 部署 | GitHub 公开仓库 + GitHub Actions → GitHub Pages | 免费 HTTPS，满足麦克风权限要求 |

已知风险：iOS 上"主屏幕模式"对语音识别的支持因系统版本而异。App 启动时会检测是否可用；不可用时提示"在 Safari 中打开"，并把跟读降级为"录音回放自评"。

## 3. 功能模块

所有学习都以**卡片**为单位，每张 3–5 分钟，可随时中断，进度自动保存。

1. **首页**：今日完成 X/目标张数、连续打卡天数、"下一张"推荐（优先级：到期词汇 → 未完成的课 → 新内容），以及全部卡片入口
2. **词汇复习卡**：听音 → 回想 → 翻面（中文 + 例句）→ 自评 认识/模糊/不认识；单次最多 20 张；每天引入 5 个新词
3. **听力跟读卡**：盲听 + 理解题 → 看原文听 → 逐句跟读（识别并把读错的词标红）→ 再盲听；支持 0.7 / 0.85 / 1.0 倍速；导入的原版音频支持整段播放和 A-B 循环
4. **知识点卡**：简短讲解 + 3–5 道"看中文说英文"，识别判定，允许多个正确答案
5. **情景对话卡**：App 角色说（TTS）→ 用户回应（识别）→ 关键表达命中即通过；可点"提示"看参考句；完成后展示更地道的说法
6. **测评**：首次使用做口语补测；每 4 周复测（听力 + 语法 + 口语），并与上次结果对比
7. **统计**：打卡日历、每日卡片数、累计时长
8. **我的资料（导入）**：批量选择文件，按文件名配对 `XXX.mp3/m4a` 和 `XXX.txt`；txt 第一行作标题，其余按句切分；生成可用于听力跟读卡的课程；课文中的生词可一键加入词汇本
9. **设置**：每日目标张数（默认 4）、默认语速、语音选择、备份导出/恢复、AI 服务（灰显，"即将支持"）

## 4. 内容组织

内置原创内容，参照新概念第二册的编排思路（短故事课文、一课一个语法点、循序渐进），**不使用新概念原文**。以 JSON 形式随代码打包：

```ts
Lesson     { id, week, title, sentences: string[], questions: {q, options, answer}[], newWords: WordId[], grammarId, dialogueId }
Word       { id, en, zh, example, exampleZh }
Grammar    { id, title, explain: string, drills: { zh, answers: string[] }[] }
Dialogue   { id, scene, turns: { role: 'app'|'user', en, zh, keywords?: string[] }[], betterSay: string[] }
```

首期内容：第 1–2 周，14 课。语法点优先安排测评暴露的薄弱项：现在完成时、一般过去时、被动语态（含情态动词）、should have done、间接疑问句语序、look forward to doing / 动名词、虚拟条件句、数字与时间听辨。

## 5. 核心算法

- **间隔重复**：简化版 SM-2。认识 → 间隔 ×2.5（首次 1 天），模糊 → 间隔 ×1.2，不认识 → 重置为当天再复习
- **跟读评分**：目标句与识别结果做小写化、去标点、数字转单词（如 "2" 转成 "two"），再按词做 LCS 比对。得分 = 匹配词数 / 目标词数，未匹配的词标红。≥80% 判通过
- **对话/句型判定**：有关键表达时必须全部命中（避免语序错误因相似度高被误判通过）；没有关键表达时整句相似度 ≥70% 即通过
- **打卡**：当天完成 ≥1 张卡片即视为打卡；完成数达到每日目标显示"达标"

## 6. 数据与备份

IndexedDB 存储：`progress`（各卡片状态）、`srs`（词汇复习记录）、`daily`（每日统计）、`imports`（导入的课文与音频 Blob）、`assessments`（测评记录）。

备份导出为一个 JSON 文件（包含进度、词汇、统计、测评和导入的课文文本，**不含音频**），可存到 iPhone「文件」App；恢复时导入该 JSON，音频需重新导入。删除主屏幕 App 或清除 Safari 网站数据会丢失本地数据，设置页会给出提醒。

## 7. 验证方式

- 每次改动执行 `npm run build`，通过类型检查
- 内容 JSON 写一个校验脚本，检查引用的 id 是否存在、字段是否齐全
- Mac 上用 Safari 本地预览，走通全部卡片流程
- 部署后在 iPhone 上实测：添加到主屏幕、断网打开、发音、语音识别、导入 mp3 和 txt
