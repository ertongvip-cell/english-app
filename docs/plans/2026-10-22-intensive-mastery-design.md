# 半严格精练掌握模式设计

日期：2026-10-22
状态：已批准

## 目标

将课程完成标准从“做过一次”改为“能够稳定听写、原速复现并迁移表达”。训练借鉴尚雯婕公开分享的少量材料高强度精练方法，并增加英英理解、客观评分、延迟复测和新场景迁移。

核心通路：

> 英语声音 → 英语概念 → 英语句块 → 英语回应

## 半严格规则

- 用户可以随时切换课程，不设置强制锁课。
- 未达到门槛的课程不能标记为“已掌握”。
- 未通过的句子和句块自动回到推荐及复习队列。
- 首页优先恢复当前材料的最薄弱步骤。
- 每次只推荐一个 2–5 分钟微任务，保持碎片化学习。

## 一课七关

### 1. 盲听理解

不显示文本，使用英文题检查人物、地点、事件、数字、时间、否定和意图。所有题答完才能进入下一关；正确率计入掌握度，不阻止换课。

### 2. 逐句听写

按 LRC 时间轴播放一句，用户键入听到的英文。评分使用词级编辑对齐，显示正确、遗漏、多余和替换词。错误额外分类为：

- 数字/时间
- 否定或极性词
- 冠词
- 介词
- be/助动词
- 时态或词尾
- 一般词汇

每句达到 90% 视为本轮通过；同一句连续两次达到 90% 才视为听写掌握。

### 3. 精听与跟读

逐句 A-B 循环；速度阶梯为 0.75×、0.9×、1.0×。记录每个速度是否通过，正常速度跟读准确率达到 85% 才完成本关。

### 4. 递减提示背诵

四级提示：

1. 完整原文
2. 关键内容挖空
3. 只显示单词首字母
4. 只显示 3–6 个关键词或完全空白

每次语音复现后按内容准确率评分；提示越少，掌握权重越高。

### 5. 原速复现

脱稿朗读或背诵整段，比较：

- 内容准确率 ≥85%
- 总时长 ≤原音 1.2 倍
- 单次明显停顿 ≤3 秒（浏览器能力允许时）
- 连续两次通过

第一版以语音识别结果和总时长为准，停顿分析作为后续增强。

### 6. 英文复述

只显示英文问题与关键词。多词关键词必须完整命中，覆盖率至少 60%；不要求逐字复现原文。

### 7. 场景迁移

在旅行、日常或工作新场景中表达相同意图。按关键含义与必要句块判断，不要求复述教材句子。

## 延迟复测

首次完成七关后，在 1、3、7、14、30 天安排复测。每次抽取：

- 1 句听写
- 1 个句块快速回应
- 1 个复述或迁移任务

复测通过标准为三项至少通过两项。失败时不清空历史，而是将失败项重新排入次日队列。30 天复测通过后课程标记为“稳定掌握”。

## 数据模型

新增 `LessonMastery`：

```ts
interface LessonMastery {
  lessonId: string
  dictation: Record<string, { bestScore: number; passStreak: number; errorTypes: string[] }>
  shadowing: Record<string, { ratesPassed: number[]; bestScore: number }>
  recall: { level: number; bestScore: number; passStreak: number }
  originalSpeed: { bestScore: number; bestDurationRatio: number; passStreak: number }
  retellCoverage: number
  transferPassed: number
  firstCompletedAt?: string
  reviewIndex: number
  nextReview?: string
  stable: boolean
  updatedAt: number
}
```

掌握数据独立于课程包。重复导入课程不会覆盖学习记录。

## 首页

首页优先展示当前精练材料和七关进度：

```text
当前材料：The Way to King Street
盲听理解    已通过
逐句听写    12/15
正常语速    8/15
脱稿复现    未开始
英文复述    未开始
场景迁移    未开始
延迟复测    0/5
```

同时保留：直接反应词块数、平均开始回应时间、中文提示次数、到期复测数量。

## 适用范围

七关训练引擎适用于所有标准私有课程包。新概念是第一批内容；以后导入播客、文章音频、字幕、工作材料时复用相同流程。没有逐句时间轴的材料不能启用精确听写和 A-B 循环，界面会说明并降级为整段训练。
