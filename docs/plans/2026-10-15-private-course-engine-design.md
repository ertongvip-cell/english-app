# 通用私有课程引擎与英语直接反应训练设计

日期：2026-10-15
状态：已批准

## 1. 目标

将现有英语 PWA 从“内置原创课程 + 简单文件导入”升级为通用私有课程平台。Mac 负责扫描、匹配、拆解和编排资料；iPhone 负责碎片化学习并在本机记录进度。首个适配器处理用户本地《新概念英语》资料，但课程模型和训练引擎不绑定教材。

核心训练目标不是中英互译，而是建立：

> 英语声音 → 英语概念/场景 → 英语回应

中文只作为初期兜底，随着熟练度提高逐步隐藏。

## 2. 总体架构

### Mac 私有课程管理端

- 扫描仓库外的个人资料目录
- 用来源适配器解析不同格式
- 显示音频、文本、时间轴和元数据的匹配状态
- 允许选择课程、设置顺序和学习起点
- 预览并编辑自动拆解结果
- 生成标准私有课程包

### iPhone PWA 学习端

- 导入标准课程包
- 按学习计划展示课程
- 独立记录卡片完成状态、词汇记忆、正确率和反应时间
- 支持跳课、标记熟悉、重学及更改当前课程
- 相同课程 ID 重复导入时更新内容但保留进度
- 暂不做 Mac/iPhone 自动同步；支持手动备份到 iCloud Drive

### 公开与私有边界

GitHub 和 GitHub Pages 只包含 App、课程包格式、解析器源码及原创内置课程。教材 PDF、LRC、MP3、OCR 结果、教材全文课程包和含课文的备份禁止进入仓库或 Pages。

## 3. 通用来源适配器

所有来源最终转换成同一个 `PrivateLesson` 模型。

1. **新概念适配器（首期）**：LRC 时间轴 + MP3 + 扫描 PDF OCR；处理第一册奇偶课合并命名
2. **通用音频适配器**：MP3/M4A/WAV + TXT/Markdown/LRC/SRT/VTT
3. **视频字幕适配器（后续）**：MP4 或在线视频导出的字幕 + 音轨
4. **文章/播客适配器（后续）**：正文 + 音频 + 元数据
5. **自建课程适配器**：用户直接录音、输入文本和训练意图
6. **工作材料适配器（后续）**：会议录音/脚本、产品介绍、汇报材料；默认最高隐私等级

没有时间轴的材料可用整段播放和系统 TTS；只有文本也能生成词汇、句块和回应练习。拥有时间轴与原音的资料可启用逐句定位、A-B 循环和同步高亮。

## 4. 标准私有课程包

每课由元数据 JSON 和可选媒体文件组成：

```text
learning-plan.json
source-book1-015.lesson.json
source-book1-015.mp3
```

核心模型：

```ts
interface PrivateLesson {
  schemaVersion: 1
  id: string
  source: { type: string; book?: string; lesson?: string; title: string }
  sentences: { id: string; text: string; zh?: string; paraphraseEn?: string; startMs?: number; endMs?: number; phonetics?: SpeechNote[] }[]
  concepts: ConceptCheck[]
  vocabulary: { word: string; definitionEn: string; zh?: string; collocations: string[]; examples: string[] }[]
  grammar: GrammarNote[]
  chunks: ReactionChunk[]
  retell: RetellTask[]
  transfers: TransferTask[]
  media?: { fileName: string; checksum: string }
}
```

`learning-plan.json` 只保存课程 ID、顺序、起点和阶段要求，不保存学习完成状态。完成状态由 iPhone 独立维护。

## 5. 六层训练引擎

1. **Sound / 听音识意**：盲听后用英文识别人、地点、行为、时间、数字和意图
2. **Decode / 逐句解码**：按时间轴逐句定位；英文原句 → 简单英文改述 → 中文兜底；标注连读、弱读和重音
3. **Vocabulary / 英英词汇**：声音 → 英文定义 → 场景例句 → 搭配 → 中文兜底
4. **Pattern / 句块反应**：英文场景提示；逐步从 5 秒压到 3 秒以内；记录正确率和反应时长
5. **Retell / 英文复述**：完整跟读 → 关键词 → 英文问题 → 事件顺序 → 30 秒自由复述
6. **Transfer / 场景迁移**：把材料表达迁移到旅行、日常聊天、工作会议和观点表达中，按交流意图而非逐字背诵判定

## 6. 中文淡出和熟练度

- 首次学习：英文优先，中文可主动展开
- 初步掌握：只显示英文定义/改述，中文位于二级提示
- 连续两次正确且反应 ≤3 秒：进入“直接反应”状态，复习不显示中文
- 反应 >5 秒、关键语序错误或依赖中文提示：重新安排句块训练

核心指标：直接反应词块数量、平均首次理解遍数、平均回应时间、英文提示成功率、中文提示使用率、复述覆盖率。

## 7. 首批路线

采用“第 1 册精选补漏 + 第 2 册主线”。先制作 6 个代表单元以验证流程：

- 015&016：护照与旅行交际
- 031&032：现在进行时
- 047&048：饮食与礼貌请求
- 067&068：周末与过去时
- 073&074：问路
- 135&136：报告与工作表达

验证后扩充到约 20 个第一册补漏单元，再进入第二册顺序学习。App 可根据错误把对应第一册基础卡插回复习队列，无需返回整册重学。

## 8. 资料处理原则

- LRC 解析时间戳、过滤元数据并保留原始行映射
- MP3 通过册号、课号、规范化标题及校验值匹配
- PDF 只在本机 OCR；OCR 结果必须可预览和人工修正
- 翻译、英英释义、语法讲解、概念题和迁移任务重新整理，不把教材讲解直接发布
- 每个课程包校验 schema、句子 ID、时间轴单调性、媒体校验值和训练引用完整性
- 课程包与备份默认放在仓库外 `英语测评/私有课程包/`

## 9. 当前不做

- 云端账号与自动同步
- 第三方服务器上传教材内容
- 第 3/4 册批量处理
- 自动发布未经人工抽检的 OCR 结果
- AI 自由对话（保留未来扩展点）
